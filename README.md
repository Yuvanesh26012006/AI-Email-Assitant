📧 Email Assistant

An intelligent Email Assistant that helps users compose, manage, and automate emails efficiently using modern web technologies and AI capabilities.

🚀 Features
✉️ Compose emails with smart suggestions
🤖 AI-powered auto-reply generation
📂 Inbox management (read, delete, organize emails)
🔍 Search and filter emails
📝 Draft saving functionality
🔐 Secure authentication system
🌐 User-friendly interface
🛠️ Tech Stack
Frontend
React.js (TypeScript)
Tailwind CSS
Backend
Node.js
Express.js
Database
MongoDB / PostgreSQL
Other Tools
REST APIs
JWT Authentication
OpenAI API (for AI-based email suggestions)
📁 Project Structure
email-assistant/
│
├── frontend/        # React frontend
├── backend/         # Node.js backend
├── database/        # DB schemas & configs
├── .env             # Environment variables
└── README.md
⚙️ Installation & Setup
1. Clone the Repository
git clone https://github.com/your-username/email-assistant.git
cd email-assistant
2. Setup Backend
cd backend
npm install
npm start
3. Setup Frontend
cd frontend
npm install
npm run dev
🔑 Environment Variables

Create a .env file in the backend folder:

PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_openai_key
